# Wiki do Laboratório de Informática

Base de conhecimento para consultar problemas frequentes de laboratório e tutoriais de uso de sistemas educacionais.

**[Acessar a wiki](https://romulogonzaga.github.io/lab_wiki/)**

## Objetivo

Reunir orientações em um só lugar para apoiar alunos, docentes e o atendimento de suporte. A página inicial organiza os tutoriais por problema e apresenta verificações antes de acionar a equipe responsável.

## Conteúdo

- Login e acesso aos computadores.
- Uso de TV, áudio e segundo monitor.
- Conectividade, pacote Office e Veyon.
- Portal Docente, SIAC e análise de frequência.
- Orientações para registrar um problema com as informações necessárias ao suporte.

## Tecnologias

HTML e CSS, com páginas estáticas, documentos e mídias de apoio.

## Executar localmente

1. Clone ou baixe este repositório.
2. Abra `index.html` em um navegador.
3. Mantenha as pastas do projeto juntas para preservar os links dos tutoriais.

O acesso a sistemas e conteúdos externos depende de internet e das permissões de cada serviço.

## Estrutura

| Caminho | Conteúdo |
| --- | --- |
| `index.html` | Página inicial e catálogo de problemas |
| `css/` | Estilos |
| `problemas/` | Tutoriais |
| `documentos/` | Materiais de apoio |
| `midias/` | Imagens e vídeos |

## Atualizar os tutoriais

Edite a página correspondente em `problemas/` e, quando necessário, seu link em `index.html`. Confira os caminhos dos arquivos e a leitura em telas menores.
