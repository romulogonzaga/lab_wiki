Informações para login

Página de solução — Login e acesso

Categoria: Login e acesso
Descrição: Orientações para acessar os computadores do laboratório usando o usuário comum.

Credenciais de acesso

Usuáriousercomum
Senha123asdASD@

Como resolver

  1. Na tela de login do Windows, clicar em Outro usuário, no canto inferior esquerdo.
  2. No campo de usuário, digitar exatamente: usercomum.
  3. No campo de senha, digitar exatamente: 123asdASD@.
  4. Conferir a grafia do usuário. Um erro comum é digitar usercomun, com N no final, em vez de usercomum, com M no final.
  5. Verificar se o servidor está ligado, pois as informações de login são puxadas dele.
  6. Se o usuário e a senha estiverem corretos e o servidor estiver ligado, o login deve funcionar.

Observações

  • Atenção especial à grafia do login: o correto é usercomum.
  • O erro usercomun é comum entre os alunos e impede o acesso.
  • Antes de concluir que a senha está errada, confirme se a opção Outro usuário foi selecionada e se o servidor está ligado.

Quando chamar suporte

Acionar suporte se o servidor estiver ligado, as credenciais tiverem sido conferidas cuidadosamente e, mesmo assim, o computador não permitir o acesso.

Dica: se o problema continuar, anote o equipamento, a sala, o horário e tire uma foto da mensagem exibida na tela.
